## 0. Decision Log (what we locked, and why)

| # | Decision | Rationale |
|---|---|---|
| 1 | Discovery cohort = **FieldEffectCrc Cohort A** (N=834; CRC 311 / HLT 462 / NAT 61; paired-end) | Largest, richest-metadata, single-technology cohort available |
| 2 | **FieldEffectCrc Cohort B** (N=30, matched tumor/normal pairs, paired-end) and **Cohort C** (N=275, single-end) are kept as **two separate, never-pooled** external validation sets | Cohort C differs in library prep (single-end vs paired-end) — a documented technical confound in the source data. Testing on it separately is a deliberate "cross-protocol stress test," directly on-topic for our research question |
| 3 | **TCGA-COAD only** (not COAD+READ) used as a third, independent external validation cohort | COAD and READ differ in mutation spectrum and immune profile (documented in literature) — pooling would need its own justification, which we're not making by default |
| 4 | TCGA-COAD's "normal" (solid tissue normal) is **not equated** with FieldEffectCrc's "HLT" (healthy) — it is treated as biologically closer to **NAT** (tumor-adjacent normal) | Dampier et al.'s own data show NAT sits transcriptomically between HLT and CRC. Evaluating the frozen model against this is framed explicitly as a "cross-tissue-state generalization test," not a like-for-like replication |
| 5 | **GSE196006 (EOCRC, ~21 patients) + GSE251845 (LOCRC, ~22 patients)**, pooled, form one unified fourth external validation cohort (~43 patients / ~86 matched tumor-normal samples) | Both accessions come from the same study, protocol, and lab (Penn State Genome Sciences core, STAR/hg38, matched design) — legitimately one cohort split across two GEO series, not two independent cohorts |
| 6 | A **within-Cohort-A mini-audit** (PCA/UMAP colored by original sub-study/site, from the `study` and `data` metadata fields) is mandatory before locking discovery CV splits | Cohort A is itself pooled from GDC, SRA-via-dbGaP, SRA-public, and BarcUVa-Seq sources — internal batch structure must be ruled out before trusting internal CV performance |

**Final architecture:**

```
DISCOVERY (nested CV, all feature selection + tuning happens here):
    FieldEffectCrc Cohort A (n=834) — CRC vs HLT primary contrast

FROZEN MODEL EVALUATED, NO REFITTING, ON:
    Validation 1: FieldEffectCrc Cohort B  (n=30,  matched pairs, same protocol as A)
    Validation 2: FieldEffectCrc Cohort C  (n=275, single-end — cross-protocol stress test)
    Validation 3: TCGA-COAD                (n≈485, tumor vs adjacent-normal — cross-tissue-state test)
    Validation 4: GSE196006 + GSE251845    (n≈43 patients / ~86 samples, matched pairs, independent lab)
```

## A. Executive Recommendation

Build a **leakage-safe, nested-cross-validated, multi-cohort external-validation study** of colorectal tumor-vs-normal classification, where the actual research contribution is **not** the classification itself (biologically easy, already done many times in the literature) but a **systematic comparison of three feature-selection strategies** (differential-expression-informed, data-driven, pathway-level) on **which one yields features that remain predictive, stable, and biologically interpretable across four independent, technically and biologically distinct cohorts.**

This design directly demonstrates the methodological maturity gained from P2.1 (cohort confounding awareness) while asking a scientifically distinct question, and produces a portfolio piece that is defensible to a skeptical reviewer, not just a "high accuracy" showcase.

**Confounding audit summary:**
- Cohort vs. platform: **confounded** between Cohort A/B (paired-end) and Cohort C (single-end) — handled by keeping C as a separate, explicitly-labeled stress test rather than pooling.
- Tissue-normal definition: **not uniform** across cohorts (healthy vs adjacent-normal) — handled by explicit labeling and a dedicated cross-tissue-state secondary analysis rather than treating "normal" as one biological category.
- Site/lab: Cohort A is itself multi-source — handled by the mandatory mini-audit (Decision 6).
- Class balance: TCGA-COAD is 10:1 tumor:normal — handled by mandatory use of ROC-AUC/PR-AUC/balanced accuracy, never raw accuracy, for this cohort.
- Gene ID/build compatibility: all four sources use Ensembl gene IDs on GRCh38/hg38 — good news, minimal re-annotation needed, but exact Ensembl release/gene-set overlap must still be checked computationally before pooling any feature lists.

## C. Literature Positioning

Tumor-vs-normal CRC classification from bulk RNA-seq is **well-established** — not a novel task. Representative prior work:
- A 2023 study (TCGA-CRC + GSE50760 discovery, LASSO + 5 ML models, external validation on GSE142279) reported a 3-gene signature (CA2, CA7, ITM2C) reaching ~99–100% AUC on external data — illustrating both that near-perfect separation is common for this task, and that such numbers alone are not a meaningful research contribution.
- Numerous other CRC prognostic/diagnostic signature papers validate on 1–5 external GEO cohorts but rarely treat cross-cohort **feature stability** as a first-class question, and rarely enforce patient-level, leakage-safe nested CV as a design principle from the outset.
- On the methods side, peer-reviewed tooling exists specifically for our exact problem (e.g., the `nestedcv` R package, built for embedded feature selection in high-dimensional transcriptomic data with proper nested CV), and there is a well-documented literature on the optimistic bias introduced when feature selection precedes CV splitting.

**Our legitimate contribution:** not "ML can classify CRC" (solved), but a reproducible, leakage-safe comparison of feature-selection strategies for cross-cohort robustness and biological interpretability, evaluated across four cohorts that differ deliberately in protocol, lab, and normal-tissue definition — explicitly designed to detect the kind of cohort confounding that undermined P2.1's first dataset.

## D. Recommended Study Design

```
Cohort A (discovery)
   │
   ▼
Outer CV (patient-level grouping; 5-fold, repeated if feasible)
   │
   ├── Inner CV: feature selection (3 strategies, done independently per fold)
   │        A) DE-informed (limma-voom or simpler filter, trained-fold only)
   │        B) Data-driven (variance/univariate filter + stability selection)
   │        C) Pathway-level (Hallmark gene sets, standardized expression)
   │
   ├── Inner CV: hyperparameter tuning (Elastic Net / RF / XGBoost)
   │
   └── Outer fold evaluation (ROC-AUC, PR-AUC, balanced accuracy, etc.)
   │
   ▼
Freeze final model (fit on ALL of Cohort A, using the winning representation)
   │
   ▼
Apply frozen model, no refitting, to:
   Val. 1 (Cohort B) → Val. 2 (Cohort C) → Val. 3 (TCGA-COAD) → Val. 4 (GSE196006+GSE251845)
   │
   ▼
Feature stability analysis (bootstrap resampling within Cohort A)
   │
   ▼
Biological interpretation (enrichment, cell-composition caveat check)
```

## E. Research Questions

**Primary RQ:**
Which transcriptomic feature-selection strategy — differential-expression-informed, data-driven, or pathway-level — produces colorectal tumor-vs-normal classification features that remain predictive across four independent cohorts differing in sequencing protocol, tissue-normal definition, and originating lab?

**Secondary RQs:**
1. How much does classification performance degrade from internal (nested CV) to external validation, and does the degradation pattern differ by feature-selection strategy?
2. Which genes are selected repeatedly (high-confidence, stable) across bootstrap resamples and across models, and are they enriched for biologically coherent pathways after correcting for background bias?
3. Does a classifier trained on tumor-vs-healthy (Cohort A) assign tumor-adjacent-normal tissue (NAT in Cohort A itself, and TCGA-COAD's "normal") an intermediate score consistent with a field effect — and does this hold across cohorts? (secondary/exploratory)
4. Do candidate stable features show associations with likely tissue/cellular composition (immune, stromal, epithelial marker genes), such that "predictive" must be qualified as "associated with tissue composition" rather than presumed tumor-cell-intrinsic biology?

---

## F. Hypotheses

- **H1:** Internal (nested CV) AUC will be high (>0.95) for all three feature-selection strategies, given the strong tumor/normal biological effect size.
- **H2:** External performance will drop most for Cohort C (single-end, cross-protocol) relative to Cohort B (same-protocol), providing a direct, quantified demonstration of technical-confound sensitivity.
- **H3:** The data-driven and DE-informed strategies will select overlapping but not identical gene sets; the pathway-level representation will show smaller performance drops across cohorts due to its coarser, more robust aggregation, at the cost of interpretability at the single-gene level.
- **H4:** A consensus set of features selected across ≥2 strategies and stable under bootstrap resampling will be enriched for well-established CRC-associated processes (cell cycle, DNA replication/repair, extracellular matrix remodeling) — consistent with, but independently derived from, the DEG signal already observed in the earlier CDDL/GSE251845 exploratory work.
- **H5 (exploratory):** Tumor-adjacent-normal samples (NAT) will receive classifier scores intermediate between healthy-normal and tumor, consistent with a field effect — but this will be evaluated as an exploratory, not confirmatory, hypothesis.

## G. Final Pipeline (raw/processed data → biological interpretation)

1. **Data acquisition & harmonization** — download all four cohort sources; verify Ensembl gene ID / genome build compatibility; record accession IDs, download dates, versions.
2. **QC & mini-audit** — PCA/UMAP of Cohort A colored by `study`/`data` source fields; confirm no dominant internal batch structure before proceeding. Repeat lightweight QC on each validation cohort separately.
3. **Preprocessing** — establish a normalization strategy defensible for cross-cohort application (e.g., within-cohort log-CPM + gene-wise standardization fit on training data only; explicit decision on whether/how to attempt any batch adjustment, with ComBat use only if independently justified per Section 16 of the original brief).
4. **Patient-level nested CV on Cohort A** — outer 5-fold (grouped by patient), inner CV for feature selection + hyperparameter tuning, for each of the 3 feature-selection strategies × 3 models (Elastic Net, Random Forest, XGBoost).
5. **Model freezing** — fit final chosen configuration(s) on all of Cohort A.
6. **External validation** — apply frozen model, unmodified, to Validation 1–4 in sequence; report ROC-AUC, PR-AUC, sensitivity/specificity, balanced accuracy, with bootstrap CIs where feasible.
7. **Feature stability analysis** — bootstrap resampling within Cohort A; build consensus feature set using pre-specified selection-frequency thresholds.
8. **Interpretation** — SHAP (tree models) / coefficients (Elastic Net) for global feature importance; explicit "SHAP describes contribution to predictions, not causation" caveat.
9. **Biological enrichment** — GO/KEGG/Reactome/Hallmark on the consensus feature set, background = genes passing the expression filter (not whole genome), BH-FDR correction.
10. **Tissue-composition check** — compare consensus features against curated immune/stromal/epithelial marker gene sets; frame any overlap as "associated with tissue composition," not tumor-cell-intrinsic discovery.
11. **Secondary/exploratory field-effect analysis** — score NAT samples (Cohort A + TCGA-COAD) with the frozen model; visualize HLT→NAT→CRC ordering if supported by the data.
12. **Write-up** — Introduction, Dataset & audit, Methods, Results (internal CV, external validation, stability, enrichment, secondary analyses), Discussion, Limitations, Conclusion.

## H. Methodological Risks

| Risk | Mitigation |
|---|---|
| Hidden batch structure within Cohort A itself | Mandatory mini-audit before locking CV splits (Decision 6) |
| Cross-cohort normalization inadvertently removing real biological signal, or leaking information | Fit all normalization/scaling parameters on training data only; no joint normalization across discovery + validation cohorts |
| Overselling near-ceiling accuracy as novel | Explicit framing throughout: classification itself is not the contribution; robustness/interpretability is |
| Treating "normal" as one biological category across cohorts | Explicit HLT vs NAT distinction maintained everywhere in code, tables, and text (Decision 4) |
| Small validation cohorts (B: n=30; GSE pooled: n≈43 patients) giving noisy external estimates | Report bootstrap confidence intervals; avoid overinterpreting point estimates from small cohorts |
| TCGA-COAD's severe class imbalance biasing interpretation | Mandatory use of PR-AUC/balanced accuracy/sensitivity-specificity; accuracy never reported alone |
| Multiple external cohorts inviting post-hoc "cherry-picking" of the best-performing one | Pre-specify that all four validation results are reported together, regardless of outcome |
| Gene ID / annotation version mismatches across cohorts silently shrinking usable feature overlap | Explicit gene-overlap audit step before any cross-cohort feature application |

- Freeze model, run once against each of the 4 validation sets in sequence, report all results regardless of outcome.

**Phase 6 — Biological enrichment & secondary analyses (explicitly labeled exploratory).**
- Enrichment, tissue-composition check, field-effect exploratory analysis.

**Phase 7 — Write-up & optional lightweight results-viewer** (only after Phases 1–6 are stable; per the brief, this must consume frozen outputs only and never influence upstream analysis).
